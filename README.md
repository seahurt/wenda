# wenda

一个简单的 Flask Web 应用，用于上传问答题并在线作答。支持手动填写答案的相似度判定，以及将打乱的答案步骤重新排序。

## 功能概览
- 上传 JSON 题库文件：文件主体为列表，每个元素包含 `ask`（问题）和 `answer`（步骤列表，顺序即正确顺序）。
- 随机抽取 N 道题作答。
- 两种作答模式：
  - **手动填入答案**：根据输入与正确答案的相似度评分，默认阈值 0.6（可调）。
  - **排序答案步骤**：将打乱的步骤上下移动后提交，检测顺序是否正确。

## 本地运行
1. 创建并激活虚拟环境（可选）。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动应用：
   ```bash
   flask --app app run
   ```
4. 浏览器访问 `http://127.0.0.1:5000`。

## JSON 格式示例
```json
[
  {
    "ask": "泡一杯绿茶需要哪些步骤？",
    "answer": [
      "烧水到80摄氏度",
      "放入茶叶",
      "注入热水",
      "等待2分钟",
      "倒出茶水"
    ]
  }
]
```

上传后可以设置抽题数量，选择作答模式并提交答案查看结果。
